## 🛠️ Catálogo Completo de Ferramentas (Tech Stack)

Abaixo, a listagem unificada de todos os softwares disponíveis no ecossistema SetupOrion v.2.8.0, organizada por categoria para facilitar sua consulta.

### 🌐 Infraestrutura, Proxy & Monitoramento
* **Traefik & Portainer:** O cérebro da infraestrutura. Gerenciamento de containers e proxy reverso com SSL automático.
    * [traefik.io](https://traefik.io/) | [portainer.io](https://www.portainer.io/)
* **Uptime Kuma:** Painel de monitoramento de status e alertas de disponibilidade em tempo real.
    * [uptime.kuma.pet](https://uptime.kuma.pet/)
* **Grafana + Prometheus + cAdvisor:** Tríade poderosa para análise de métricas e performance de hardware/containers.
    * [grafana.com](https://grafana.com/)
* **NetBox:** Ferramenta de gerenciamento de infraestrutura de rede (IPAM e DCIM).
    * [netbox.dev](https://netbox.dev/)
* **Duplicati:** Sistema de backups inteligentes e criptografados para serviços de nuvem.
    * [duplicati.com](https://www.duplicati.com/)
* **PgBackWeb:** Interface web simplificada para gestão e agendamento de backups PostgreSQL.
    * [pgbackweb.io](https://pgbackweb.io/)
* **VaultWarden:** Versão leve e segura do Bitwarden para gerenciamento de senhas da equipe.
    * [bitwarden.com](https://bitwarden.com/)

### 🤖 Inteligência Artificial (IA) & Automação
* **n8n:** O rei da automação de fluxos de trabalho baseada em nós (alternativa ao Zapier).
    * [n8n.io](https://n8n.io/)
* **Dify AI:** Plataforma Full-Stack para criação e orquestração de apps baseados em LLMs.
    * [dify.ai](https://dify.ai/)
* **Ollama:** Interface para rodar modelos de linguagem (Llama 3, Mistral) localmente na sua própria VPS.
    * [ollama.com](https://ollama.com/)
* **Flowise & LangFlow:** Construtores visuais de fluxos LangChain para criar agentes inteligentes.
    * [flowiseai.com](https://flowiseai.com/) | [langflow.org](https://www.langflow.org/)
* **ActivePieces:** Automação low-code moderna com foco em facilidade de uso e conectores SaaS.
    * [activepieces.com](https://www.activepieces.com/)
* **Anything LLM:** Stack completa para transformar seus documentos em uma base de conhecimento privada para IA.
    * [useanything.com](https://useanything.com/)
